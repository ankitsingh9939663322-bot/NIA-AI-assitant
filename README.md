# NIA Full Android v2

Alexa-style command-router Android starter.

Implemented:
- Voice input with Android SpeechRecognizer UI
- Voice output with Android TTS
- “Hey NIA” prefix is accepted in commands
- Persistent local memory for people/relationships
- Forget-memory command
- Time/date
- Google search
- YouTube / Google / WhatsApp Web / Instagram / Gmail
- Android Settings / Wi-Fi / Bluetooth
- Alarm / Timer
- Camera / Calculator
- Maps
- Dialer for a number
- Help command
- Premium dark UI

Examples:
“Hey NIA, open YouTube”
“Hey NIA, search latest news”
“Hey NIA, set alarm”
“Remember Rahul is my brother”
“Who is Rahul?”
“Forget Rahul”

Important:
This is not a literal Amazon Alexa clone. Android and Alexa have different system permissions and services.
Always-on “Hey NIA” requires a dedicated wake-word/background service and careful Android permission handling.
A true open-ended AI brain requires an API/backend; do not put a secret API key directly in an APK.
